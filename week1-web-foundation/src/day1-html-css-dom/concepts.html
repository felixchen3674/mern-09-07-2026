Day 1 — Concepts Reference

Try to answer each one yourself, then click to reveal it.

1. Basic concepts

Foundational stuff — straight from the lecture and/or comes up constantly in interviews. If you're shaky on any of these, that's the priority to fix.

What happens by default when a form is submitted?

The browser reloads the page — a GET request to the current URL. That's why a submit handler in JS almost always starts with event.preventDefault().

Is <input> self-closing, or does it need a closing tag?

Self-closing — write <input /> or plain <input>, never <input></input>.

What are the four layers of the CSS box model, from outside to inside?

margin → border → padding → content.

What is the alt attribute on <img> for?

The text a screen reader speaks for that image, and what shows if the image fails to load. Not optional — always fill it in.

What's the difference between id and class?

id must be unique — one element per page. class can be reused across as many elements as you want.

What is semantic HTML?

HTML that uses tags describing the meaning of content, not just its appearance — <header>, <nav>, <article>, <footer> instead of a generic <div> for everything. It's how screen readers and search engines understand your page's structure.

What are HTML attributes?

Extra information added to an opening tag as name="value" pairs, e.g. <img src="cat.png" alt="A cat">. They configure or describe the element without adding visible content by themselves — id, class, src, href, data-*, etc.

What is the CSS box model?

Every element renders as a box made of four layers, outside in: margin → border → padding → content. box-sizing: border-box makes width/height include padding and border; the default content-box doesn't.

flexbox vs grid — what's the difference?

Flexbox lays items out along one axis (a row or a column) — good for toolbars, navbars, centering. Grid lays items out along two axes at once (rows and columns together) — good for a whole-page or card-grid layout.

What is responsive design, and how do you ensure it?

Design that adapts to different screen sizes instead of only looking right at one. Achieved with relative units (%, rem, vw) instead of fixed pixels, flexible layouts (flex/grid), responsive images, and @media queries to change styles at specific breakpoints.

What is a media query?

A CSS rule that applies a block of styles only when a condition about the viewport is true — most commonly a width breakpoint: @media (max-width: 600px) { ... }.

2. Advanced concepts

Less commonly asked, and some go beyond what today's lecture covered — mostly "gotcha" interview trivia and things that sharpen how you code without being asked often.

What is HTML injection, and how do you avoid it?

When untrusted input (like user text) gets inserted into the page as raw HTML instead of plain text, letting an attacker inject their own tags — including <script> (this is XSS). Caused most often by setting .innerHTML with unsanitized input. Avoid it by using .textContent for plain text, or a framework's built-in escaping, instead of building HTML strings by hand.

What's the difference between <head> and <body>?

<head> holds metadata that isn't rendered (title, charset, meta tags); <body> holds everything the page actually displays.

What is the HTML <meta> tag?

A void element inside <head> carrying metadata about the page — not rendered, but read by the browser, search engines, and social link previews. Common ones: <meta charset="UTF-8">, <meta name="viewport" content="...">, and Open Graph tags.

What is the critical rendering path?

The sequence a browser follows to turn HTML/CSS/JS into pixels: parse HTML → build the DOM, parse CSS → build the CSSOM, combine them into the render tree, compute layout, then paint. "Optimizing" it means minimizing what blocks this sequence (e.g. render-blocking CSS/JS) so the page appears faster.

What is async and defer in the <script> tag?

Both let the HTML parser keep working while the script downloads, instead of the default behavior of blocking parsing. async runs the script the moment it finishes downloading (order vs. other scripts isn't guaranteed); defer waits until the HTML is fully parsed and runs scripts in the order they appear. Use defer when a script needs the DOM ready, async for independent scripts like analytics.
