# ATS Keyword Bank

Applicant tracking systems match literal strings. Use the exact spelling recruiters search for, and include **both** the acronym and the full name once (e.g. "Continuous Integration/Continuous Deployment (CI/CD)").

Only copy keywords you can defend. See [01-tech-stack-by-tier.md](01-tech-stack-by-tier.md).

## Keywords to avoid unless you built something with them

Angular, NestJS, Java, Spring Boot, React Native, Kubernetes (as a headline skill), MongoDB, OpenAI API, Pinecone, Redux Saga. These appear in the interview question bank as comparison topics, not hands-on skills.

## Formatting tips

- Use the standard heading "Technical Skills" or "Skills"; ATS parsers look for it.
- Plain text only: no icons, skill bars, star ratings, or tables for the skills section.
- Repeat your top 5 keywords in experience or project bullets too, not only in the skills block. Recruiters search for evidence as well as lists.
- Match the job description: if the posting says "RESTful services", write "RESTful services", not just "REST APIs".
